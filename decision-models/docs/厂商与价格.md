# 厂商归属与官方 API 价格（2026-11-23 核对）

价格口径：**按输入 token 计费，输出免费**，这是决策模型的共同计价方式（不生成文本）。
New API 的 `ModelRatio` 换算：`ratio = 单价($/1M) ÷ 2`（ratio 1 = $0.002/1K = $2/1M）。

| 模型 | 厂商 | 发布方 | 官方价（$/1M input） | New API ratio | 来源 |
|---|---|---|---|---|---|
| **Bison 31B** | Base Labs（Baseten 内部研究团队） | Baseten Model APIs | **$0.10** | 0.05 | [bison-1 模型卡](https://huggingface.co/baselabs/bison-1)、[Baseten](https://www.baseten.co/library/bison-1/) |
| **Elephant 9B**（elephant-1） | Base Labs | Baseten Model APIs | **$0.035** | 0.0175 | [Baseten 定价公告](https://www.baseten.co/resources/changelog/elephant-1-and-mammoth-1-pricing/) |
| **Decider v1.3**（26B） | Perplexity | Perplexity Decisions API | **$0.02** | 0.010 | [Perplexity Decisions 文档](https://docs.perplexity.ai/docs/decisions/decisions) |
| **Decider Flash v1.3**（4.5B） | Perplexity | Perplexity Decisions API | **$0.01** | 0.005 | 同上（Flash 是半价档） |
| **GLiDE-0.4B** | Fastino Labs | Fastino API（`POST /v1/systemone`） | **$0.04** | 0.020 | [Fastino GLiDE 文档](https://docs.fastino.ai/concepts/glide.md) |

补充：
- 对照 Mammoth 27B（非本批）= $0.10/1M，和 Bison 同价。
- GLiDE 官方明确 output tokens 免费、无 per-request fee；Perplexity 也明确 output 免费、无 request fee。
- Baseten 的 bison 卡写 "$0.10 per 1M tokens"，elephant 公告写 "per 1M input tokens"，口径一致。

## 自建成本对照（Spark GB10，单请求串行、未计 batching）

按 0.10 美元/GPU 小时粗算（GB10 整机功耗约 240W，按 0.6 元/度 ≈ $0.08/h）：

| 模型 | 单任务延迟 | GPU·h / 1M 任务 | 自建成本/1M | 官方价/1M | 结论 |
|---|---|---|---|---|---|
| Bison 31B | 154 ms | 42.8 | ≈$4.3 | $0.10 | 官方便宜得多（他们按 token 计，一份输入只算一次） |
| Elephant 9B | 79 ms | 21.9 | ≈$2.2 | $0.035 | 同上 |
| Decider v1.3 | 289 ms | 80.3 | ≈$8.0 | $0.02 | 同上 |
| Decider Flash | 178 ms | 49.4 | ≈$4.9 | $0.01 | 同上 |
| GLiDE-0.4B | 6.9 ms | 1.9 | ≈$0.19 | $0.04 | 自建更划算 |

注意：官方价是**按 token** 计，自建是**按 GPU 时间**计，两者只有在"输入很短、QPS 很高"时才可比。
New API 里按官方 token 单价计费，主要是为了给内部用户一个"对外等价"的账，不代表真实成本。
